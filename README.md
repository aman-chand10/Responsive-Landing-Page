🚀 NexGen — Responsive Landing Page

A modern, responsive landing page built with HTML5, CSS3, and JavaScript. This project demonstrates clean UI design, responsive layouts, interactive navigation, and essential front-end web development concepts.

✨ Features
Responsive Design — Adapts to mobile, tablet, and desktop screen sizes.
Interactive Navigation — Fixed navigation bar with scroll-based styling effects.
Mobile Menu Toggle — Opens and closes the navigation menu on smaller screens.
Modern Hero Section — Eye-catching gradient background, introductory content, and call-to-action buttons.
Feature Cards — Highlights responsiveness, interactive navigation, and lightweight front-end development.
About Section — Introduces the project and its development objectives.
Smooth Scrolling — Provides smooth navigation between page sections.
CSS Animations — Includes a floating visual card and hover effects.
Font Awesome Icons — Adds icons to navigation, feature cards, and social links.
Google Fonts — Uses the Poppins font family for modern typography.

🚀 Getting Started

Follow these steps to run the project locally.

Prerequisites

You only need a modern web browser and Git. No Node.js installation or package manager is required.

1. Clone the repository
bash
git clone https://github.com/AmanChand-leo/Responsive-Landing-Page.git

2. Navigate to the project directory
bash
cd Responsive-Landing-Page

3. Fix the asset filenames

Ensure that task1.html references the actual CSS and JavaScript filenames in your repository.

Inside the HTML <head>, use:

HTML
<link rel="stylesheet" href="task1.css">


At the end of the HTML <body>, use:

HTML
<script src="task1.js"></script>

4. Run the project

Open task1.html in your browser, or use the Live Server extension in Visual Studio Code for a convenient local development experience.

That's it! No build step is necessary.
